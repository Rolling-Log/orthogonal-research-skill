orthogonal-research-skill V3.1.0
发布日期：2026-10-08。基于 V3，用途适配、第一性原理、证据边界和对抗审查方法沿用 V3。

新增开篇代表图片：位于一句话定义及来源说明之后、执行摘要之前；1–4 张单行横排，每张短说明 1–10 个字符，原比例缩放，图片与说明、来源同页，后文自然分页。PDF 与 HTML 均支持 representative-images 容器，短说明计入封面字数。

本文件夹即 skill 根，SKILL.md 与 agents、scripts、references、assets、vendor 同级。安装时只选择这一份；同名 skill 不适合同时安装多个版本。
GitHub 默认分支仅放当前版；旧版保存在版本标签和历史发布中。最新版下载包仅包含 orthogonal-research-skill/，不包含旧版、测试档案和主页素材。

构建器使用内置纯 Python ReportLab 子集与中文字体；公开包不附带 Pillow/curl 的旧 Windows 二进制。常规 JPEG/PNG/PDF 构建不要求安装这些二进制。图片格式转换需要当前环境提供兼容工具。
新 sources 继续使用 method_version="3"、coverage.balance_policy="diagnostic"。结构校验和渲染成功不等于研究判断已通过审查。
内置 sample 文件是虚构模板，仅用于结构和渲染测试。对平台兼容性的陈述以对应版本的实际 CI 结果为准。
