# 使用示例

## 应触发完整流程

### 输入

> 用横纵分析法研究一家机器人公司，重点看过去五年的技术路线和全球竞品，做成 PDF。

### 行为

- 用户未指定路径时，在桌面创建带时间戳的分装研究包并以当前日期为截面；
- 用中文、英文和主要玩家当地语言研究纵向历史与全球竞品；
- 建来源台账和 coverage；
- 生成转折时间线、核心指标图和生态图；
- 按 v1 主结构写 1–3 万字报告；
- 使用紧凑深蓝编号角标、必要的段后说明和连续编号参考文献，构建并逐页复核 PDF。

## 不应触发完整流程

### 输入

> 什么是激光雷达？两句话回答。

### 行为

直接简答，不启动长报告、制图或 PDF。

## 同一证据的二遍改写

证据稿先锁定事实、判断和引用，不追求最终节奏：

```markdown
2019 年公司完成硬件模块化，2021 年把同一核心组件用于第二条产品线，2023 年又用于第三条产品线。三条产品线的验证周期口径不同，不能直接比较月份。我的判断是，早期模块化降低了后续扩品类的工程摩擦。{{@S012,@S027 | 两家公司披露的验证周期定义不同，只比较方向。}}
```

阅读稿只调整顺序、段落和转场，不增删事实或来源：

```markdown
2019 年做出的模块化选择，当时没有立刻变成销量，却给后来的扩张留出了一道门。到 2021 年，同一核心组件进入第二条产品线；2023 年，第三条产品线也沿用了它。

这三条线披露的验证周期口径并不一致，所以绝对月份不能硬比。[[blue:我的判断是，模块化真正缩短的不是某一个公开数字，而是后来扩品类时反复重做底层工程的摩擦。]]{{@S012,@S027 | 两家公司披露的验证周期定义不同，只比较方向。}}
```

验收时核对两稿的事实节点仍为 2019、2021、2023，作者判断没有越过证据，来源仍严格为 `S012`、`S027`。若第二遍新增事实、删除反证或改动来源映射，必须退回证据稿重做。

## 错误示例

- 把“注册用户”“月活用户”“付费席位”画在同一条增长线上：拆图或只保留同口径数据；
- 图谱塞 40 个节点和 70 条边：保留核心生态，另拆人物/资本、产品/技术；
- Markdown 留图表代码等待 PDF 执行：先运行视觉渲染器；
- 编号角标引用不存在的 `S099`：补全来源台账或删除无法证明的主张；
- 文末编号与首次引用顺序不一致：按构建错误修复，不手工改正文编号；
- 任一文化语言组低于 20% 或高于 80%：继续检索或完整登记并披露例外；
- 海外来源受阻却不写限制：在 coverage、执行摘要和研究限制三处同步披露。
