# V3 能力迁移与回归依据

此表保留原文件名以兼容引用，记录 V3 的真实取舍，不能把所有变动都称“增强”。历史版本原件不变。状态是规则迁移说明，**不表示本版或某份报告已经验收通过**；实际结果须附成品和原文证据。配额被替换后尤其要检查必要机制与纵横深度没有退化。

| 原能力或规则 | V3 处理 | 实现位置 | 实质验收 |
|---|---|---|---|
| 产品、公司、技术、概念、行业、人物的系统研究；排除简单释义/单一事实/纯摘要 | 保留，明确入门工作理解 | SKILL frontmatter、report-spec 对象适配 | 适合对象的必要机制与路线，不能全部套商业模板 |
| 联网核验、打开原始材料、论文与正式版本 | 保留 | SKILL 联网、protocol 检索 | 搜索摘要没有冒充原文，日期/版本可核验 |
| 纵向、横向、补充材料分工 | 条件化 | SKILL 并行 | 复杂任务合并去重，简单任务不强凑团队 |
| 海外与当地语境发现、跨语言遗漏检查 | 保留 | protocol 覆盖、adversarial 遗漏 | 没有未解释的关键路线/地区遗漏，网络缺口具体披露 |
| 20%–80% 文化比例、2–4 目标组与固定来源数量 | 经授权替换为诊断 | sources coverage、builder 政策分支 | 新 diagnostic 不凑数；旧缺政策仍 strict，未知政策拒绝；偏斜按具体主张处理 |
| 一手溯源、真实口碑、独立性去重 | 保留并区分证据角色 | protocol 来源角色/evidence | 公告没有替代实效测量；口碑有样本边界；转载不同域名不重复算根 |
| 每竞品必须官方/独立/社区三视角 | 条件化 | protocol 覆盖、SKILL 横向 | 体验结论有合适观察，概念机制不为了三视角硬找口碑 |
| 连续两轮空新增才结束 | 经授权替换为问题停止 | protocol 停止、research-log | 承重问题已支持/限缩/悬置，继续检索价值与未知明确 |
| 起源、推动者、初始形态、关键转折与危机 | 保留 | SKILL 纵向、protocol 阶段卡 | 今天与起点差异可解释，不只是发布流水账 |
| 选择逻辑、备选、约束、结果与路径依赖 | 保留，连接目标机制 | SKILL 双轴、adversarial 第一性原理 | 选择有机制和证据，实际约束与替代路线可比较 |
| 固定 3–6 阶段、5–10 历史节点 | 条件化 | protocol 阶段、visual-system | 阶段随机制改变，短历史不造转折；渲染边界仍遵守 |
| 无竞品、少竞品、多竞品三种情形 | 保留；代表数条件化 | SKILL 横向、protocol 比较 | 直接/间接/历史替代清楚，纳入与排除理由可辩护 |
| 统一比较口径、核心差异、使用代价、生态位 | 保留 | protocol 比较、report-spec | 不同配置/地区/定义不强排名，差异形成机制可理解 |
| 历史塑造当下位置、比较对象的纵向对照、优势和包袱根源 | 保留 | SKILL 交汇 | 至少有实际可支持的两轴联系，不能把时间相邻写成因果 |
| 固定三条洞察和三未来剧本/概率 | 条件化 | SKILL 交汇、protocol 未来 | 需要预测才给情景，触发与反证真实，无依据不编概率 |
| 纵向 6,000–15,000、横向 3,000–10,000、交汇 1,500–3,000、全文 1–3 万字及竞品最低字数 | 经授权替换为问题深度与阅读路径 | report-spec 主干、SKILL 写作 | 明确长篇需求保留深度；短篇仍覆盖必要机制，不能靠字数判优 |
| 一句话定义—纵向—横向—交汇—来源主干；不生成目录页 | 保留 | SKILL、report-spec | 双轴实质展开且顺序可读，阅读路径用真实标题 |
| 叙事、层层解释、主观判断与回环；套话/编造禁区 | 保留；机械每节场景/桥梁与段长条件化 | report-spec 文风 | 自然转场和术语解释，不虚构场景，不用修辞代替因果 |
| 证据稿与阅读稿二遍改写 | 保留 | report-spec、examples | 事实/边界/反证不被润色偷换，实质修订回证据稿 |
| 用户工作/探索目的、已知知识、阅读预算 | 增补明确执行 | SKILL 输入、protocol 简报 | 提取已有信息，仅实质歧义追问，探索不被改成采购 |
| 承重主张定位、实际支持、边界、时间口径和混合根 | 增补可审查记录 | claims evidence、protocol | 独立审查先识别承重判断再读原文，不以字段完整免审 |
| 第一性原理五项乘积与 0–3 自评分 | 经授权删除并替换 | adversarial、SKILL | 目标、机制、约束、路线和检验落实到成品推演 |
| 交付末尾五轮红队、至少五主张 | 前移且按风险集中 | claims review、adversarial 五类检查 | 强替代、区分证据、撤销条件和真实修订影响正文；纯日期不硬造反方 |
| A4、原字体/配色/边距、全宽正文、章节竖条、引用块/表格/图注/页眉页脚 | 保留 V2.2 | report-spec、builder、CSS | 真实 PDF 逐页外观核验，不凭文本抽取判通过 |
| 固定封面署名 | 保留 V2.2 修复：删除显示 | builder、report-spec | 无姓名，author 仅可选元数据 |
| 自动封面全文字数与预计阅读时间 | 保留 V2.1/V2.2 | reading_metrics、report-spec | 内容编辑后统计联动，估算不冒充理解时间 |
| 标准加粗与受控语义色 | 保留；每章至少一次条件化 | report-spec | 强调真正承重信息，颜色不替代证据 |
| 紧凑来源编号、段后/单格说明、全名文献与访问日 | 保留 V2.2 | builder、report-spec | 首次顺序与双向文献一致，坏引用失败，unknown 日期不造值 |
| 六类数据图与逐边出处图谱 | 保留 V2.2 | visual-system、render_visuals、scene | 数据与关系可溯源，静态可读，事实/假设区分 |
| 固定图总数、至少两张产品图、连续文字页限制 | 条件化，保留真实产品形态证据 | visual-system、SKILL | 图片数量按解释作用，素材缺口明确；无装饰图凑页，密图拆分 |
| 图片下载/转换与网络失败容错 | 保留 V2.2 | proxy_fetch、visual-system | 获取完整性实际核验，TLS 保留；可选 Windows 资源不宣称通用 |
| 桌面唯一分装包、显式输出优先、文件名及相对路径 | 保留 V2.2 | init_workspace、SKILL | 遵从用户位置、无覆盖、完整产物路径真实 |
| 自包含 PDF、HTML 调试稿与构建日志 | 保留 V2.2 | builder、report-spec | 渲染状态与研究审查状态分开，HTML 失败不误判 PDF |
| 来源/主张/数据结构检查 | 增补窄范围检查器 | check_research、protocol | ID 双向/日期/高影响可审查性可检；不宣称语义 PASS |
| 单层发行与显式副本检查 | 保留 V2.2 | check_package | 不再产生漂移入口，不读历史兄弟目录 |
| 平台兼容与真实运行声明 | 保留限界 | 自检、报告交付说明 | 本机日志只支持本机，其他系统如实标未实机验证 |

新增字段或删除配额的效益须用实际任务比较验证。没有真人计时或大规模样本，不能宣称普遍提升阅读效率、所有对象质量或全平台可靠性。
